# supportops

Paquete Python del curso «Observabilidad de agentes de IA en producción»: el agente de soporte **SupportOps v0**
(sin instrumentar), un proveedor LLM agnóstico (`mock` determinista por defecto), herramientas simuladas, un
simulador de tráfico con semilla fija y un inyector de fallos. Instalación: `pip install -e agent-observability-course`.
La API completa está en `agent-observability-course/_tools/INTERFACES.md`.
